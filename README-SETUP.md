# BuildTech Engineering Systems website starter

## Files
- `index.html`: homepage and product cards
- `products/`: one detail page per product category
- `styles.css`: responsive layout and colours
- `script.js`: mobile menu and current year
- `assets/`: temporary SVG illustration placeholders

## Publish with GitHub Pages
1. Download and unzip this folder.
2. Open your repository: https://github.com/BuildTechEngineeringSystems/BuildTech-Engineering-Systems
3. Click **Add file → Upload files**.
4. Upload the contents of this folder (not the outer folder itself), including `index.html`, `styles.css`, `script.js`, `assets/`, and `products/`.
5. If GitHub asks you to replace the existing `README.md`, you can keep it; this starter uses `README-SETUP.md`.
6. Commit the changes to the `main` branch.
7. Open **Settings → Pages** and confirm the source is set to deploy from `main` and `/(root)`.
8. Wait a few minutes, then refresh your published site.

Published address should remain:
https://buildtechengineeringsystems.github.io/BuildTech-Engineering-Systems/

## Replace the sample images
The images in `assets/` are illustrations, not photographs of your actual machines. Replace them with your own JPG/PNG/WebP files and update the `src` path in the HTML. Keep the filenames simple, e.g. `peanut-coating-machine.jpg`.

## Add a YouTube video
On a product page, replace the `.video-placeholder` block with an embed like this, using your own video ID:
`<iframe width="100%" height="315" src="https://www.youtube-nocookie.com/embed/YOUR_VIDEO_ID" title="Machine demonstration" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen></iframe>`

## Before publishing
- Replace placeholders with actual machine photos and tested specifications.
- Check the WhatsApp phone number and address in the HTML.
- Do not publish unverified capacity, power, price, safety or performance claims.
- Test the website on both desktop and mobile.
